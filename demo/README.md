# Real ten-card demonstration / 实际十卡案例

The included PPTX/PDF and README screenshots are **actual edited presentations**, derived from the Passmore et al. paper, with scientific captions and narrative drafted/reviewed during testing. They are **not** evidence that the current CLI automatically reproduces the same design from arbitrary PDFs.

Scientific content and individual quantified claims still require independent review. Supplementary evidence for some numbers was unavailable. See `../docs/DEMO_PROVENANCE.md`, `../docs/KNOWN_LIMITATIONS.md`, and `../NOTICE_THIRD_PARTY.md` for attribution, scope, and limitations.
