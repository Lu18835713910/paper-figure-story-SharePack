# v0.1.0-rc.1 — First SharePack preview candidate

**This is a release candidate / experimental preview, NOT an approved public beta.**

## In this package

- Core `sharepack` CLI for PDF indexing, specified Figure region cropping, story schema audit/validation, and editable PowerPoint rendering.
- Standalone workflow (reviewed story is mandatory; PFS not required).
- Optional read-only PFS v1.1.1 knowledge and Figure bridge plus experimental A/B logic projection helpers.
- Actual ten-page PowerPoint case-study images, with third-party attribution and licensing statement.

## Known limitations

- General-purpose engine is not the same as the bespoke ten-card demo's final visual generator; do not assume pixel-for-pixel reproduction on other papers.
- Source-linked scientific story content is prepared or verified by a human/Agent, not authored with verified correctness by a fully autonomous CLI.
- Clean Windows install, independent cross-paper E2E, final Office appearance and scientific review remain outstanding.
- Dense two-Figure pages require zoom at 400px mobile width.
- Project code license selection is pending. Article figure material used in demo is credited under CC BY 4.0; review special third-party credit lines if applying elsewhere.

Read the [README](README.md), [limitations](docs/KNOWN_LIMITATIONS.md), and [third-party notice](NOTICE_THIRD_PARTY.md).
