# Real product screenshots, with scope and provenance

The images under `docs/images/` are screenshots/overview generated from actual **editable PowerPoint** research cards. They are not mockups or generative reconstructions.

- `ten_card_overview.png`: all ten cards from the reviewed PFS-assisted Passmore example (PowerPoint production, not a general CLI proof).
- `story_map.png`: page 3, research frame; narrates two study branches.
- `path_deviation.png`: page 5, Figure 1e/f path-deviation explanation (not speed).
- `protein_control.png`: page 9, Figure 3 protein-control branch.
- `standalone_design_reference.png`: two-page standalone-leaning design reference, from an actual PPTX, not strict uncontaminated standalone blind testing.

**Attribution and rights:** See [`NOTICE_THIRD_PARTY.md`](../NOTICE_THIRD_PARTY.md), the [article](https://doi.org/10.1038/s41467-025-67848-5) and the [CC BY 4.0 license](https://creativecommons.org/licenses/by/4.0/). The article's experimental panels are authentic; SharePack authored the card layout and Chinese interpretation, some of which require ongoing domain review.

**Source status:** The scientific story drew on earlier PFS-generated test data and Agent curation. Raw PFS A/B model files and source-index snapshots are **not included** in this public demonstration. The PFS version displayed in the screenshots reflects an upstream test campaign, not that the CLI reproduced all ten cards automatically.
